# SHAX v3.4.0 | Distribution Edition

Professional single-file installers for SHAX, the Adobe After Effects motion and project workflow extension.

## What changed

The plugin's existing runtime and tools are preserved from v3.3.1. The version label is updated to 3.4.0 and native installer build scripts are included. **This is a distribution update, not a new motion-engine release.**

| Platform | File generated by CI | User experience |
|---|---|---|
| macOS | `SHAX-v3.4.0-macOS.pkg` | Double-click, follow Apple Installer, restart After Effects |
| Windows | `SHAX-Setup-v3.4.0.exe` | Double-click, welcome / install / finish, restart After Effects |

After installation: **Window > Extensions (Legacy) > SHAX**.

The Mac package installs to the [Adobe-supported system CEP directory](https://helpx.adobe.com/creative-cloud/apps/integration-with-other-apps/manage-plugins/cep-uxp-plugin-transition.html). The Windows installer uses the current user's CEP directory, requiring no administrator permission. They set CEP `PlayerDebugMode` because the plugin is not yet signed.

## Builds

The GitHub Actions workflow `.github/workflows/build-installers.yml` compiles both installers on their **native host systems** and publishes a **prerelease** containing the two downloadable installer files, if GitHub Actions is enabled with write permissions. Use GitHub **Actions > Build SHAX installers > Run workflow** to rerun the build.

To build manually:

- **Mac:** On macOS, run `bash packaging/macos/build-macos.sh`. Requires Apple `pkgbuild` and `pkgutil`.
- **Windows:** On Windows with NSIS installed, run `makensis packaging\windows\SHAX.nsi` from the repository root.

The `dist` directory in this source archive contains no prebuilt binaries. GitHub Actions builds `.pkg` and `.exe` from the same files, so **do not rename a ZIP or shell script to `.pkg`/`.exe`**.

## Signing warning

The installers are **unsigned and unnotarized** development builds. Gatekeeper / SmartScreen may warn about them. Sign the Windows EXE with an Authenticode certificate and the Mac PKG with a Developer ID Installer certificate; notarize the Mac package before wide public distribution. This preview should be tested on both operating systems before claiming that every AE 2023+ environment is supported.

## Privacy and previous versions

- Personal Vaults and Brand Kits are **not** deleted or migrated during installation.
- The Mac installer installs system-wide, while older per-user SHAX extensions may still exist. CEP ordinarily uses the extension with the higher version.
- The Windows installer replaces only the `com.shax.panel` runtime directory and leaves personal library data intact.
- An installed CEP extension contains readable HTML/JS/ExtendScript. An installer alone **does not hide or encrypt source code**, especially while the GitHub repository is public.

## Source layout

- `CSXS/`, `index.html`, `css/`, `js/`, `jsx/`: Adobe CEP extension runtime
- `packaging/macos/`: macOS `.pkg` build, installation hook
- `packaging/windows/`: NSIS `.exe` script and visual assets
- `packaging/RELEASE_NOTES.md`: public prerelease description
- `.github/workflows/build-installers.yml`: continuous installer building
