# SHAX short introduction

**SHAX brings motion-design essentials into one After Effects panel.**

Instead of switching between multiple tools, you can browse reusable animations, adjust timing, organize compositions, align layers, apply brand styling, and keep animated scene packs in a reusable Vault.

**Highlights:** 56 animation presets • Visual previews • Motion Vault • Align and Anchor Point • Brand Kit • Project Organizer • Light/Dark UI.

**Current stage:** Public demonstration / release candidate. Full host-level testing on macOS and Windows is ongoing.

For a first look, start with the [interface screenshots](../README.md) and the [installation guide](INSTALLATION.md).
